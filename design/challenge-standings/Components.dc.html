Data each row needs

Client can't read another user's daily_activity (owner-only RLS). Add one SECURITY DEFINER RPC.

challenge_standings(p_challenge_id bigint) returns table ( user_id uuid, display_name text, username text, avatar_url text, is_friend boolean, is_me boolean, cumulative_miles numeric, -- SUM(daily_activity.distance_miles) week_miles numeric, -- trailing 7 days last_synced_at timestamptz, finished boolean ) -- WHERE activity_date BETWEEN challenge.start_date -- AND COALESCE(challenge.end_date, CURRENT_DATE) -- AND daily_activity.activity_type = challenge.activity_type

Then trailPosition.ts already maps cumulative_miles → lat/lng + nearest trail_points.label for the marker and the "Mile 142 · past Franconia Ridge" line — run it per row.

Activity type: add activity_type to daily_activity and sync per-type from HealthKit (DistanceWalkingRunning, DistanceCycling) / Health Connect. The RPC then filters to the challenge's type — so a running challenge counts runs only.
