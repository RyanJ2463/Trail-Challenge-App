TRAIL CHALLENGE

Design system

Colour, type and application guidance for the hiking / walking / running challenge app. Direction: minimalist outdoor tech — the interface recedes so the map and the numbers carry the screen.

DIRECTIONS CONSIDERED
Minimalist outdoor tech CHOSEN

Cool near-white, hairline greys, one slate accent, monospaced numbers. Instrument-like — a trail computer, not a lifestyle app. The typeface does the character work.

Earthy trail-inspired

Warm off-white paper, forest-green ink, muted earth accents — the direction the current lib/theme.ts already ships. Grounded and calm; more "national park" than "instrument".

Energetic urban athletic

Near-black and white with one electric accent. Performance-first, closer to Strava / Nike Run Club. Louder and more competitive; strong for city running, weaker for slow hikes and streaks.
